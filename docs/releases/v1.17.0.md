# OptiPlex NOW v1.17.0 Closed Beta

This is a **Linux amd64 testing prerelease**, not a production-stable release or an accepted Beta 1 milestone. It targets an existing owner-approved Tailscale/SSH/Wolf server. The project does not install or configure a new host.

## Changes since v1.16.1

- Graphical Tailscale installation, status checks and browser sign-in on supported Debian/Ubuntu-family systems, with improved setup-wizard discovery and cancellation.
- Graphical SSH host verification and authorization. Routine first-client setup should no longer require the tester to launch a terminal, though local system permission prompts and separate server-side preparation may be required.
- Graphical Moonlight installation, Wolf-pairing and setup feedback improvements.
- Dashboard initial geometry adapts to the usable monitor area, including smaller laptop/projector displays.
- Portable defaults no longer embed the developer's account, host address or media URLs. Existing saved configuration and pairing are intended to remain intact.
- Separate native modules for Wolf transport, Tailscale/wizard network lifecycle, service probes, tray actions, host metrics, immutable worker target selection and asynchronous encrypted backup.
- Expanded regression, sanitizer, installed Debian package and simulated onboarding-helper tests.

## Known limitations and acceptance status

**Fresh-device acceptance has not yet been performed.** In particular, Tailscale installation and login, first-time SSH authorization, genuine Wolf/Moonlight pairing, media login, video/audio/controller streaming, and preservation of an existing installation's identity must be checked on real client hardware. Successful GitHub Actions tests do not prove these flows.

The beta is a client for a configured personal server. Host installation, owner email approvals, self-service identity, native Windows/macOS packages, transactional restore, and turnkey household access are not shipped.

## Testing instructions

1. Download `OptiPlex-Now_1.17.0_amd64.deb` and `SHA256SUMS` **from this tagged release**, and verify the checksum.
2. Prefer a spare supported Linux client. Use the graphical software installer, or `sudo apt install ./OptiPlex-Now_1.17.0_amd64.deb` if necessary.
3. Test Tailscale, setup wizard, SSH trust, Moonlight, pairing, Games and Videos in that order.
4. Preserve the existing device's NOW config, SSH keys, and Moonlight pairing. Never delete a known-working identity to simulate a new install.

See [Beta 1 acceptance](https://github.com/SteezyMode/OptiplexNow/blob/main/docs/BETA-ACCEPTANCE.md) and [Current status](https://github.com/SteezyMode/OptiplexNow/blob/main/docs/CURRENT-STATUS.md) for checks and limits.

There is no server upgrade in this release. Published assets are immutable; corrective builds will use a new patch version.
