# OptiPlex NOW v1.18.0 Closed Beta

**Linux amd64 test build. Not a public-alpha or production-stable release.** This package includes the existing-host NOW client plus a separate experimental **NOW Host** setup window. It does **not** deliver a complete Jellyfin, VPN-downloader or gaming-server installation.

## Changes since v1.17.0

- Include the newer source work for the real read-only Server Setup review and opt-in **advanced clean-host Wolf installer pilot**. Candidate hosts are Ubuntu or Pop!_OS 24.04 amd64 with a separately verified AMD, Intel or NVIDIA GPU path. The installer requires owner confirmation and OS authentication. NVIDIA additionally needs a verified installer checksum.
- Add managed Wolf configuration/state, immutable upstream image input, explicit project ownership checks and interruption records. A running container is still **not** proof of a successful video, audio or controller stream. There is no accepted installer recovery, update or uninstall workflow.
- Reject outdated Server Setup eligibility responses when GPU, render-node or installer fields change during a check.
- Preserve the v1.17.0 graphical Tailscale, trusted SSH enrollment, Moonlight/Wolf pairing, portable URL defaults, tray, media links and backups.
- Clarify the proposed product: independent games, personal Jellyfin video and owner-administered, VPN-isolated downloads. Those requirements are **not** all implemented or verified in this package.

## Recommended first test: existing-host Linux client

Use a non-destructive fresh profile on a spare Linux client such as Linux Mint XFCE. A newly created standard Linux user with a new home directory exercises empty NOW configuration, new SSH user identity, Moonlight preferences and browser logins without destroying the original user's credentials.

**Limit:** Tailscale's daemon and node enrollment are system-wide. A new Linux user on the same OS is not a fresh Tailscale/OS install. Do not log out or reset Tailscale just to emulate a blank machine.

1. Download this **tagged release**'s versioned `OptiPlex-Now_1.18.0_amd64.deb` and `SHA256SUMS`. Verify the checksum. The checksum file also includes the unversioned alias; keep both files when checking the full file.
2. Install/upgrade the package through the desktop package installer (or `sudo apt install ./OptiPlex-Now_1.18.0_amd64.deb`).
3. Sign into the *new standard user* and launch NOW from the applications menu. Confirm the initial setup contains no developer-specific host, username or media URLs and fits the client's screen.
4. With Tailscale already connected on this machine, verify NOW detects existing network membership without reinstalling the daemon. Discover the correct server and explicitly verify any new SSH host fingerprint before authorizing. **Do not trust a changed fingerprint.**
5. Install/select Moonlight through the GUI if missing; pair the newly unpaired user identity to the already configured, owner-approved Wolf host. Verify a real independent game stream with video, audio and controller input. Confirm the host screen and controls remain usable.
6. Test Videos using the owner's Jellyfin login; check disconnect/reconnect, errors and UI feedback. Check that a member is not granted server administration.
7. On the original Linux user, confirm existing NOW configuration, Tailscale connectivity, SSH keys, Moonlight identity and saved service URLs still work after the package upgrade.

**Do not** remove `~/.config/optiplex-desk`, `~/.ssh`, Moonlight storage or Tailscale node state from a working account to manufacture a fresh setup. The disposable Linux test user can be kept for repeat regression tests.

## Unverified and intentionally excluded

- Full fresh-OS Tailscale installer, clean physical Wolf host provisioning, actual GPU encode, secure streaming and host reboot/recovery remain **unaccepted** until observed on real hardware.
- The advanced Wolf installer must **never** run against a working Wolf/Docker host or the developer's existing reference server. Ordinary clients should use an existing preconfigured host.
- Unified NOW sign-in, email device approvals, native Windows builds, managed Jellyfin and VPN downloader, restricted remote file/download roles, and the 15-minute install target are future requirements.

See [Beta 1 device acceptance](../BETA-ACCEPTANCE.md), [Host installer scope](../HOST-INSTALLER.md) and [current status](../CURRENT-STATUS.md).
