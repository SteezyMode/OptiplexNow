# NOW v1.21.0 — Current Alpha

**Official Linux .deb for approved devices using an existing, owner-configured server.**

The project name OptiPlex NOW remains provisional. This is the recommended package for the current alpha test, **not** certification that the entire Private Alpha 1 roadmap is complete.

## Install

Download **OptiPlex-Now_1.21.0_amd64.deb** from this release and open it with the Linux desktop package installer. Supported target: 64-bit Linux Mint / Pop!_OS / Ubuntu. Existing NOW settings, Moonlight pairing credentials and device identities are intended to be preserved. The client does not install or restart host services.

## Included

- Dashboard, Games, Videos, Downloads and Settings navigation.
- Games through the existing owner-approved Wolf/Moonlight streaming host.
- Jellyfin integration using the owner's existing server.
- Downloads split into Transfers (automatic refresh) and Search (up to 100 paginated results, currently returned after a bounded search).
- Per-transfer speed, progress and ETA, plus owner-only pause/resume, reannounce, recheck and Remove. **Remove keeps downloaded files.**
- Choose an approved media destination before adding a torrent; VueTorrent remains under Advanced.
- Gluetun health indicator, optionally linking to AirVPN's account page. This does not prove outage kill-switch safety.

## Host compatibility — important

**This is an updated client, not a host updater.** The reference host must have the matching restricted owner broker, queue, VPN status and torrent management modules for native Transfers to function. The old host deployment does not have those modules. The server update and full physical test remain outstanding; this release must not be described as end-to-end accepted until they pass.

Torrent traffic is intended to use the separate Gluetun VPN; prior reference-host checks confirmed actual tunnel routing and default-DROP firewall, **not** a simulated VPN disconnect. Do not grant untrusted users direct Wolf access to the owner's Steam session; Moonlight/Wolf pairing and NOW owner authorization are distinct.

## Status and rollback

- Client package and source are checked through GitHub CI, including GTK smoke tests, Python regression tests and native sanitizer checks.
- Real client/server acceptance for the newly added Transfers controls, clean first-run enrollment and complete VPN failure handling remains pending.
- If the new client fails, reinstall the older versioned v1.20.0 Debian package from [previous releases](https://github.com/SteezyMode/OptiplexNow/releases). Preserve existing owner keys, Steam/Moonlight identities and settings.
