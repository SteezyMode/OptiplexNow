# NOW v1.21.1 — Current Alpha

**Current official Linux installer for approved devices on an existing personal NOW server.**

Download **OptiPlex-Now_1.21.1_amd64.deb**, open it in your normal Linux package installer, and upgrade in place. The application keeps existing profile settings and restricted owner-device credentials. Existing older installers remain available under Releases for rollback.

## Fixes

- **Search fills the Downloads page.** Its scrollable results list now expands to the available height, like Transfers, rather than staying approximately 150 pixels tall.
- **Search stops waiting for all plugins.** The owner-authorized qBittorrent search returns the first validated results after its first nonempty poll. If plugins are still running, NOW marks those results **partial**; subsequent searches can discover more. No-results searches may continue polling for up to 12 seconds.
- Existing folder picker, magnet validation, search SID isolation, 100-result cap and ephemeral search cleanup are unchanged.

## Host compatibility

**Client installation does not change the server.** The faster search additionally requires updating the host's restricted `server/download_search.py` module. The other newer Transfers/VPN UI functions require the compatible host owner-broker, queue and management modules; the previously inventoried reference host did not yet have all of them. Back up the existing modules and apply only reviewed host-side changes; do not restart or change qBittorrent, Gluetun, Wolf or Jellyfin for this patch.

## Verification

The Search-layout and fast-return behavior have automated GTK/Python regression tests, but have **not yet been physically accepted** on the reference host and MacBook Air with this exact client/host combination. The publisher performs its own clean source build, package validation, GTK smoke and Python tests.

The broader Private Alpha 1 end-to-end gates—fresh approved client, protected file operations, true VPN disconnect fail-close, and clean-host adoption/install—remain open. This is a Current Alpha patch, not full product certification.
