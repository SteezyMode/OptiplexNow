# OptiPlex NOW v1.21.10 — Current Alpha

**Owner GPU power control, with an unchanged-looking Dashboard shortcut.** The one official Linux amd64 `.deb` upgrades the existing NOW client and includes prior main-branch reliability fixes. No additional installer or server management service is required.

## Dashboard and optional LACT power controls

- The existing GPU utilization/temperature readout looks unchanged and is now clickable. With GPU power management enabled, a click opens the dedicated GPU control window; otherwise it opens **Settings → Host GPU** to explain the optional feature.
- **Disabled on fresh clients:** no LACT access, no wattage fields and no errors if LACT is absent. The owner opts in and saves a *per-device* setting; it is not propagated through exported server presets.
- When available, the Dashboard explicitly labels the **configured current power limit / driver-advertised maximum**, e.g. `CAP 55/70 W`, **not instantaneous draw**. Live power consumption remains available in the one-click detailed GPU window, not in the VRAM row. It silently omits that extra field if the host cannot communicate with the LACT Unix socket or power bounds are unavailable.
- The dedicated GTK control offers **Power Saver**, **Balanced**, **Performance**, and a custom whole-watt slider bounded by the detected GPU-supported range. Detail view includes GPU model, power draw, cap, temperature, utilization, clock, and a *read-only* NVIDIA P-state.
- Power changes are made through **the owner's existing administrator SSH connection** to the LACT Unix socket on the host. No LACT TCP listener, new host daemon, automatic host changes, broader SSH key, sudoers modification, GPU fan curve, clock offset or forced performance state.
- LACT configuration updates preserve unrelated fan/clock settings and invoke its confirmation mechanism. The host helper also performs an **NVIDIA driver readback** and does not report success if the resulting cap differs from the request.

## Compatibility and upgrades

- This release is for owner-operated, authorized Linux clients accessing an existing host. GPU power management requires a supported NVIDIA driver and an already-running LACT service with appropriate Unix-socket permissions. An unsupported GPU or missing LACT leaves the base NOW client usable without GPU power management.
- The approved host service is **not** reconfigured by client installation. Keep the existing LACT and NOW host configurations intact. The package remains independently installable on Linux Mint, Ubuntu and Pop!_OS where the original client is supported.
- Previous latest official package: **v1.21.9**. The 1.21.10 version supersedes even unreleased `1.21.9+pr239.*` packages. Older immutable releases remain available from GitHub for rollback.

## Verification and acceptance

- Source tests cover clean-install default-off behavior, persisted opt-in, original GTK label styling, the invisible Dashboard click target, narrow settings callbacks, invalid or multi-GPU inputs, LACT socket request/response format, preservation of unrelated GPU settings, failed writes, and the driver's post-change power-limit readback.
- Native GTK, isolated Xvfb launch, installed-package smoke, full Python suite, sanitizer checks and checksum creation must pass for the **exact tagged source** in the publishing workflow before the official .deb appears.
- Owner feedback from the previous PR test installer indicates the UI is functional; this does **not** replace an independently recorded, real-device power-cap change/readback plus restore test. Hardware acceptance of GPU power control remains open until logged evidence is collected. Existing Private Alpha 1 Games/Video/Downloads/VPN and clean-host release gates also remain open.
- Installing or opening NOW does not configure LACT, alter a running GPU, restart Wolf, Jellyfin or VPN services, or grant new remote permissions.
