# OptiPlex NOW v1.21.11 — Current Alpha

**Small-window and UI consistency update.** This is an in-place update to the existing amd64 `.deb` download. No server setup or service configuration is changed.

## Small window responsiveness
- Fix an oversized window minimum caused by the three equal-width Dashboard metric columns and the added GPU cap readout. The GPU label now permits ellipsis instead of forcing the whole window wide.
- Under 720 px window width, CPU/GPU and RAM/VRAM stay as a two-column grid, with the storage selector moved below at full width. Above that width storage returns alongside the metrics.
- Existing **SERVER POWER** buttons retain their automatic two-by-two grid below 560 px; they now become reachable because the Dashboard can shrink further.
- Hide the influence of inactive Settings and other main pages on the overall window minimum.
- Settings action buttons fit their own captions instead of stretching to the entire page width, while keeping the existing padding and actions.

## Visual consistency
- **Open Video Library** uses exactly the same tile styling and 56-px target height as **Play Steam**, replacing the solid orange CTA.
- The smaller secondary Dashboard GPU label now reads `cap 55/70 W` rather than an all-caps word. Only an opted-in GPU owner sees this extra datum; live consumption is unchanged in detailed Host GPU controls.

## Verification and release safety
- Source layout-contract tests, real GTK Settings callback/spacing tests, native AddressSanitizer/UBSan, full Python tests and installed `.deb` smoke run in CI; the GTK smoke also inspects available X11 minimum-width hints.
- This small patch does **not** touch LACT APIs, GPU driver power behavior, owner permissions, Steam/Wolf, Jellyfin, VPN or download services. Current-owner hardware acceptance remains distinct from CI tests.
- The previous official **v1.21.10** release and checksums remain immutable for rollback.
- The latest-download alias in the README remains unchanged and resolves to this release after successful publication.
