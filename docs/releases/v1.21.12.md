# OptiPlex NOW v1.21.12 — Current Alpha

**Standard issue UI polish release.** This is an in-place upgrade to the official x86-64 Linux `.deb`, preserving your existing local settings and host setup.

## Refined visual identity
- Consistent understated graphite and copper controls, clear keyboard focus and button-label contrast.
- Balanced typography and less crowded Dashboard heading; no changes to the existing status and GPU data.
- Host GPU Power window uses the same dark GTK theme as the main application. The LACT cap presets, status queries, SSH, privileges and actual GPU power behavior are unchanged.

## Better Settings home
- Replace six tiny left-aligned Settings actions with a balanced two-column card menu at normal widths.
- Collapse to one full-width column below 540 px for small laptop windows. Keep existing Settings destinations, Save/Cancel and advanced options intact.

## No collision at narrow Downloads widths
- Separate Downloads header/VPN health indicator from Refresh and Advanced · VueTorrent buttons.
- The existing authenticated Transfers, Search and embedded advanced VueTorrent functionality are unaffected.

## Release safety
- Keep the existing published v1.21.11 release and its checksum files immutable for rollback.
- New `v1.21.12` assets include a versioned `.deb`, stable `OptiPlex-Now_amd64.deb` alias, and `SHA256SUMS`.
- Source and installed Debian smoke tests, native GTK tests, Python tests and sanitizer checks must pass in exact-head CI and again in the official release workflow.
- This release changes client presentation only. It does not install/change the reference host, containers, NVIDIA driver, LACT daemon, Jellyfin, Wolf, Tailscale or VPN configuration.

This is still **Current Alpha**, not sign-off of the three-pillar Private Alpha 1 acceptance contract.
