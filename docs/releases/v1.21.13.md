# OptiPlex NOW v1.21.13 — Current Alpha

This alpha update promotes the tested Downloads usability work from PR #242 into the
official Linux x86-64 installer. It retains the existing Dashboard, Games,
Videos, Settings and advanced VueTorrent functionality.

## Downloads: familiar folder selection

- Selecting a search result now opens the **actual GTK system folder chooser**,
  instead of a custom file-picker UI. Use the normal sidebar, bookmarks,
  create-folder controls and file-navigation shortcuts.
- On a remote client such as a Mac mini, the chooser opens the **OptiPlex host**
  over SFTP, not the client's local drives. A normal SSH/SFTP login to the host
  is required; NOW's restricted owner-enrollment key alone is not an SFTP login.
- Download folders are chosen explicitly. No old `Torrent-Downloads` path,
  mounted drive or previous download is imposed as a default.
- The owner broker verifies that any selected host folder maps to an existing,
  writable qBittorrent Docker bind mount. Browsing a server drive is not
  proof that qBittorrent can write there.
- The reference OptiPlex's expanded Docker mounts are a **separate host setup
  change**, not an automatic installation behavior.

## Transfers and Search

- Compact native transfer rows and context-menu actions, including pause,
  resume, recheck, reannounce, view torrent files, remove while keeping data,
  and separately confirmed remove-and-delete.
- Search can retrieve results beyond the old 25-entry limit with the updated
  host-side search broker, where the upstream search plugins provide them.
- Existing Advanced · VueTorrent remains accessible.

## Safety and installation

- Existing torrents, download directories, qBittorrent configuration, VPN
  routing and media libraries are not moved or rewritten by installing this
  client package.
- Dangerous delete operations remain owner-authorized and limited to the
  exact selected torrent and an existing verified downloader storage mount.
- Remote Downloads features require the **matching host package**. The
  installer does not silently update the reference server or its SSH keys.
  The packaged `owner-host-upgrade.py --check` reports whether the owner
  broker is already up to date; no activation is needed in that case.
- Local folder selection appearance has been reviewed on the reference
  client; full new-drive download lifecycle and wider-device acceptance
  are deferred to later alpha validation. This is not a general-purpose
  public host installer.

## Rollback and verification

- The previous v1.21.12 download and release checksums remain available.
- This release is rebuilt from its tagged source, verifies the resulting
  Debian package, runs the automated Python/native GTK and installed-package
  smoke tests, and publishes a stable `OptiPlex-Now_amd64.deb` download alias
  plus `SHA256SUMS`.
