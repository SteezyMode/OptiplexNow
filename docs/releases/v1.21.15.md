# OptiPlex NOW v1.21.15 — Current Alpha

This release promotes the owner-tested Music client from PR #245 to the official
Linux package while retaining existing Games, Videos, Downloads, owner approval
and VPN boundaries.

## Music: local playback on owner-approved clients

- Native library browsing, album and artist views, playlists, liked songs,
  search, shuffle and automatic paging while scrolling.
- Compact, responsive Music interface matching NOW's charcoal/coral styling.
  The sidebar stays anchored beside the expanding song list; track counts do
  not mistake the first 200 fetched songs for the library total.
- Local mpv playback with play/pause, next/previous, seek, local volume,
  now-playing artwork and tray controls. Tray Music opens the Music tab.
- Existing DroppedNeedle accounts can be linked once through the restricted
  host-side owner flow. Approved clients obtain their own revocable Music access
  without each creating a new server account. Music credentials remain out of
  process arguments and shareable presets.
- Optional read-only album-art/metadata audit. It does not overwrite music tags.

## Other interface improvements

- Removes redundant top-level page titles; Downloads places VPN status on the
  Refresh toolbar, preserving space for transfers.
- Music cover loading follows the scroll viewport; requested cover art is no
  longer restricted to the first 16 album cards.

## Evidence and release limits

- PR #245 exact candidate build 1559: both GitHub CI jobs passed, including
  792 automated Python/native regression tests, GTK/package checks and native
  sanitizers.
- The owner exercised local Music library browsing, playback and the
  redesigned client on Linux Mint MacBook and Pop!_OS Mac mini, and selected
  this preview as the new main installer. This is **not** proof of fresh-host
  installation, all player failure modes, mobile discovery, or third-party
  tester acceptance.
- **Existing configured host required:** the standard Debian client package
  does not automatically install or reconfigure DroppedNeedle, slskd, Wolf,
  Jellyfin, qBittorrent, VPN, SSH keys or Tailscale. Existing server ownership
  and per-device approvals still apply. The host's compatible restricted Music
  broker must already be installed and configured for integrated Music access.
- Music remains optional; Private Alpha 1's Games, Videos, and protected
  Downloads/Files physical acceptance checklist is **not complete**.
- No existing media or server credentials are changed by publication. Use
  Settings and the existing approved owner provisioning route for onboarding;
  do not distribute host admin credentials to clients.

Previous official v1.21.14 and its checksums remain available for rollback.
