# OptiPlex NOW v1.21.16 — Downloads Search Locked (Current Alpha)

This release promotes the owner-tested PR #253 Downloads client and verified host owner bridge to the **official Current Alpha `.deb`**. Music, Games, Videos and other v1.21.15 features remain included. The public brand remains a development codename; the product is being developed as **Bruiser**.

## Downloads search

- **API Bay and Bitsearch search concurrently in every category**, including **All** (default), Movies, TV, PC Games, Music and Software. The compact selector narrows results, not engine coverage.
- Native results arrive progressively, and repeated 40-character BitTorrent infohashes are deduplicated across providers and result pages. The 25-result first page is not a hard search cap.
- Reviewed Nova plugins use bounded HTTPS JSON requests and validated direct magnet links. No unsupported 1337x Cloudflare workaround, browser indexer or tracker scraping.
- Preserves existing owner-only transfer operations, per-download destinations, file browsing and management, advanced VueTorrent, Gluetun isolation and Jellyfin/Wolf independence.

## Deployment and safety

- Upgrading the client package includes the matching restricted owner broker **but does not automatically install, enable or reconfigure qBittorrent plugins, Docker, VPN, SSH keys or user credentials**. Hosts using the new Downloads search require both the bundled reviewed API Bay and Bitsearch plugins to have been installed and enabled explicitly by their owner using the included reversible tool.
- The versioned source-pinned activation and rollback utility is included at `/usr/share/optiplex-now/search/manage_dual_search.py`; the old API Bay-only migration utility remains available for historical recovery.
- Approved devices use the same restricted credential; unapproved devices are not granted access by upgrading the package.

## Evidence and limits

- On November 3, the owner successfully activated both providers on the reference OptiPlex: 12 installed API Bay TV magnets and 9 Bitsearch PC-game magnets. The matched `.deb` PR build was installed on the host, Linux Mint MacBook and Pop!_OS Mac mini, and the owner reported Downloads searches and interface working well on those devices.
- Source PR #253, exact preview commit `6e36e4e930f9bec7efc8b98873df033563eca684`, passed GitHub Actions build, native sanitizers, `825` Python regression tests and installed Debian package smoke tests (run #1587).
- **Not full Private Alpha 1 acceptance.** Clean-host automated downloader provisioning, independently checked real VPN fail-closed behavior, cross-device fresh enrollment, safe recovery and uninvolved tester walkthroughs still need physical proof; no data migration or VPN reconfiguration is part of the release.

The previous official **v1.21.15** remains published and immutable as a rollback option. The v1.21.16 release publishes a versioned `.deb`, the stable `OptiPlex-Now_amd64.deb` front-page alias, and checksums after its own CI validation.
