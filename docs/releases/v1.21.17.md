# OptiPlex NOW v1.21.17 — Music Private Alpha Lock

This release promotes the owner-tested compact native Music UI and the
read-only, per-device favorites-informed Discover polish to the official
Current Alpha `.deb`. Bruiser remains the product direction; Debian
package/binary names are intentionally unchanged for compatibility.

## Music: owner-accepted baseline

- Local OpenSubsonic audio playback, queue, shuffle, seek, playback controls,
  playlists, and liked songs; consistent heart controls for songs, albums and
  artists, with distinct ID-based server operations.
- Album action icons are inline with metadata instead of taking another row.
  Flat 25px song listings, smaller artwork, and a single horizontal mini-player
  row with an unobtrusive seek line maximize track visibility on the owner's
  1024×768 projector. Like/unlike/playlist success no longer shows a persistent
  banner; actionable errors still appear.
- Player controls, Mac mini tray title/open action and approved-device account
  integration preserve existing behavior. No system-tray menu structural change.
- Discover retains DroppedNeedle's existing catalog and candidate sections.
  This user's own OpenSubsonic favorites optionally provide known-artist and
  genre signals: new artists with **explicit matching genre metadata** may
  be prioritized within the original suggestions; novel-artist sections put
  already-liked artists behind unseen artists; followed/rediscover sections
  keep upstream order. If metadata or approved app-password access is missing,
  Discover behaves as before. No external scrobbling or transfer of favorites
  to recommendation services; no auto request, follow or download of any kind.
- Podcasts are deliberately outside this release and remain a separate
  prospective feature. If built, the intended UX is name-based podcast search,
  follow, streaming and optional manual downloads, without RSS pasting.

## Installation and compatibility

- The front-page `OptiPlex-Now_amd64.deb` alias points to this release only
  after its own gated publication build and test suite finish successfully.
- Updating an approved client does **not** create a server, restart Docker,
  install VPNs, change host credentials, or enable downloader services.
  The Music server remains a separately configured private host.
- This is a private alpha validated on an existing owner-configured household
  network; fresh-host provisioning, account consolidation, credential
  lifecycle hardening and independent tester acceptance are still unfinished.
- The previous immutable v1.21.16 release remains available for rollback.

## Verification

- Owner physically tested the initial compact v1.21.16+pr256.1618 candidate
  on Pop!_OS Mac mini and approved it for the private alpha.
- Music Discover preference ranking extends that accepted layout and is
  separately covered by offline deterministic regression tests: per-user
  `getStarred2` reads, novel artists, exact genre matches, unmatched and
  missing credentials, fail-open lookup and no automatic requests/downloads.
- Final CI and release artifact checksums are produced by the release workflow;
  a green PR build alone does not publish an official release.
