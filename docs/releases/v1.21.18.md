# OptiPlex NOW v1.21.18 — Owner-accepted Music Discover and discography

This release promotes the **owner-tested** Bruiser (legacy package name: OptiPlex NOW) music client to the front-page Current Private Alpha `.deb`. The owner confirmed that the test build from PR #269 installed on the Pop!_OS Mac mini and that artist discography navigation worked. The existing host stack is not modified by the client package.

## Music accepted for this alpha

- Existing OpenSubsonic library playback, shuffle, queue, mini-player, playlists and favorites are retained.
- Music → Discover now presents compact **clickable, artwork-led categories**, rather than a flat long list of suggestion sections.
- Personalized recommendations appear first; limited dynamic mix and `Because You Listen to [artist]` categories follow actual DroppedNeedle/ListenBrainz recommendations, not hardcoded preferences. Global trending is last.
- Search in Discover searches the **external catalog** rather than placing already-owned library songs first.
- **Explore Artist** uses DroppedNeedle's real authenticated `GET /artists/{artist_mbid}/releases` endpoint to show album, EP and single discographies with correct MusicBrainz identities.
- Explicit `Add to Library` is available for requestable albums. Requested/already-owned states are displayed; a heart or discovery suggestion never silently initiates acquisition.
- The Fresh Releases grouping no longer includes `Missing Essentials` back-catalog albums or old anniversaries. In particular, a 2011 album is not treated as a new release.
- The owner verified the Music → Discover tile interface and subsequently verified artist-discography behavior in the PR #269 client on the Mac mini.

## Release boundary and outstanding work

Music is **accepted as the current private-alpha baseline**, not declared feature-complete for a future commercial product.

- **Open issue #261:** Some local albums, including *Blue Sky Noise* and Kid Cudi's *Man on the Moon: The End of Day*, have missing artwork. Automatic persistent server-side cover resolution is a separate unreleased host change. Do not claim artwork is fixed in this `.deb`.
- **Open issue #262:** Discovery Radio/full-track unfamiliar-music streaming is exploratory and requires authorized audio sources. No universal Spotify-like catalog playback exists in this release.
- **Single-track requests:** DroppedNeedle already supports the backend endpoint, but the Bruiser GTK Discover UI does not yet expose individual-track search/request controls.
- **Discography pagination:** Large artist catalogs exceeding the current 200-item response need pagination.
- Fresh-host reproducible installation, internal credential consolidation and independent end-user approval still remain broader alpha-exit requirements.

## Installation, rollback and security

The front-page alias `OptiPlex-Now_amd64.deb` changes only when the gated publisher builds, runs the full tests and smoke checks, creates immutable tag `v1.21.18`, and uploads both the versioned .deb and SHA256SUMS. The previously published `v1.21.17` remains available for rollback.

Installing the client package does **not** provision a music server, restart Docker containers, install VPNs, enable downloading, expose new network listeners, or change the host's persistent DroppedNeedle Discover workaround. It is for owner-approved devices on the existing Linux household server.
