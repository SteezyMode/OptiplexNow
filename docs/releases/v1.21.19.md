# OptiPlex NOW v1.21.19 — Bruiser Music Home and Discover recovery (Private Alpha)

This release updates the Linux desktop client from v1.21.18. It contains the
Music features reviewed under PRs #273, #275, and #276. It does **not** make
changes to the host DroppedNeedle container by installing the .deb.

## Music Home

- Replaces the flat partial album-list Home with a Spotify-like, vertically
  stacked feed of horizontally scrollable shelves.
- **Jump Back In** (actual recently played/favorite albums), **Made for You**,
  **Fresh Releases**, **Artists to Discover**, **Your Playlists**, and
  **Recently Added** appear only when real content exists.
- Music suggestions originate from DroppedNeedle's approved catalog, never
  invented recommendations. Existing music remains playable; catalog entries
  are suggestions-only until an explicit user request.
- The full album collection remains accessible under **Your Library**.

## Discover

- A successfully fetched Discover feed is cached locally and privately for
  the approved device and host. Server restarts do not immediately erase it.
- On a truly empty server result, Bruiser can trigger a single cooldown-limited,
  authorized server recommendation-cache refresh. No music is downloaded.
- An updating state and bounded retry replace misleading blank results during
  a backend rebuild.

## Individual tracks

- Catalog albums expose their track lists and an **Add Song** action for each
  MusicBrainz recording. The entire album remains requestable separately.
- Acquisition requires an explicit user action and an approved DroppedNeedle
  device connection; liking tracks never auto-downloads anything.

## Artwork

- Client card-art worker timeout accommodates verified missing-cover lookups.
- The optional **host-side** artwork resolver v3 corrects gaps in earlier
  v1/v2 fixes: genuine MusicBrainz v3/v4 groups without representative covers
  can consult bounded, official release editions from the *same* group.
- For synthetic local UUIDv5 album identities, metadata matching handles
  accent equivalence and a uniquely matched reissue whose tag year differs
  from the original release year.
- The host installer is in `deploy/music/install_artwork_fix.py`. It pins
  the currently running approved image, verifies the Discover budget patch,
  preserves existing persistent mounts, saves rollback data, and recreates
  only DroppedNeedle. The .deb does **not** perform this upgrade.

## Validation scope

All local and CI unit, native sanitizer, GTK smoke, package and install
checks must pass in the release workflow before publication. The listed
artwork improvements are code-tested, but recovery of any individual
host-library cover (including Brand New's *Deja Entendu*) requires visual
verification after the host updater is applied. Discover also depends on
upstream data availability and device authorization.

The existing Home server, library media, credentials and download policies
are not altered by the client-only package.
