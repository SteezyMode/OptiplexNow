# OptiPlex NOW v1.21.19 — Music Home and recovery

November 4, 2026 — Current Alpha

## Music
- New vertically scrolling **Music Home** with distinct horizontal shelves for Jump Back In, Made for You, Fresh Releases, Artists to Discover, Playlists, and Recently Added. Library collections remain available separately.
- External catalog recommendations and local listening now live side by side without pretending unowned music is playable or automatically requesting/downloading it.
- Recover the previous approved-device Discover feed when DroppedNeedle temporarily reports no suggestions during an update or restart. Trigger one authenticated refresh at most every ten minutes if the upstream server genuinely has no suggestions, and retry a bounded number of times while it rebuilds.
- Browse an artist's discography and choose either a full-album request or individual song request from catalog album Tracks. These operations require existing approved owner/device authorization.
- Allow additional asynchronous artwork lookup time when the server needs a bounded secondary image provider.

## Host artwork (owner maintenance only)
- Server-side artwork v3 is a **separate, explicit host installation**. The optional installer can safely upgrade an existing Bruiser DroppedNeedle artwork v1/v2 Docker image without changing music files or unrelated containers. It preserves the pinned Discover hotfix and the same persistent volumes.
- The resolver now handles correctly identified real MusicBrainz release-group IDs as well as synthetic local ones. Where native/local and Cover Art Archive sources do not return art, the server may consult the **already-enabled AudioDB provider** with a verified artist+album title match and cache successful images.
- This .deb **does not modify or deploy** the host Docker stack. Live artwork and Discover results require host/client acceptance, and missing artwork may still occur if providers have no image or are not enabled.

## Packaging
- One amd64 .deb for desktop clients, named `OptiPlex-Now_1.21.19_amd64.deb`, plus the current `OptiPlex-Now_amd64.deb` convenience asset and SHA256SUMS.
- No music acquisitions are triggered by liking or browsing.
