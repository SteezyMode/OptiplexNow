# NOW v1.21.2 — Current Alpha

**One official Linux `.deb` for the current main build.** This replaces v1.21.1 as the normal download. No source checkout, PR artifact, or experimental channel is required.

## Search is no longer trapped at 25 partial results

- The initial search remains fast: show qBittorrent's first validated matches without imposing a 12-second pause.
- **MORE RESULTS** explicitly makes a fuller, bounded search against the same enabled qBittorrent plugins, up to 100 results. It may take up to twelve one-second polls; if plugins are still running, results are honestly marked partial.
- Native Search uses clickable **NAME / SIZE / SEEDERS / PUBLISHED** table headers; a second click reverses the order. Smaller files first is the default. Unknown size, seed count, or publication date sorts last.
- The optional publication date is a search-plugin publishing timestamp, **not** the date the owner added a torrent to Transfers.
- Selecting a magnet still opens the restricted approved-folder picker; search cannot add a torrent automatically.

## Required existing-host backend

**Installing this client `.deb` alone does not update the owner host.** The More Results request and date metadata require matching, separately adopted host `download_search.py` and `owner_games_request.py`. The currently deployed reference host was previously found to lack other newer Transfers modules too. Upgrade owner-restricted host modules as one verified, backup-safe set, not by installing random PR files. Do not modify or restart Docker, Wolf, Gluetun, qBittorrent, Jellyfin, or owner keys for this client update.

## Acceptance and rollback

Source-level GTK sorting, search protocol, owner authorization, partial/full search and package tests run through CI. This exact client-plus-reference-host combination has **not yet been physically accepted**. The remaining Private Alpha 1 host adoption, Transfer actions, new-client enrollment and VPN disconnect tests remain open.

For rollback, reinstall `OptiPlex-Now_1.21.1_amd64.deb` from earlier releases and restore any backed-up host modules. Existing accounts, approval keys, downloaded files and Steam/Jellyfin state must be preserved.
