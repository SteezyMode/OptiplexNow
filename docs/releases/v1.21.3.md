# NOW v1.21.3 — Current Alpha

**The single official main-branch Linux client installer.** Replaces earlier experimental Search behavior in v1.21.2.

## Search: continuously updated results, familiar table

- One qBittorrent search starts and remains active while its enabled plugins search. **Results appear as they arrive** and newly found results append automatically; no additional More Results button or mandatory delay before showing the first match.
- The native results table shows **Name | Size | Seeders | Leechers | Published**. Every heading is clickable and a second click reverses ascending/descending order. Size defaults smallest-first; unknown metadata is marked as unavailable and sorted last.
- Pages show 20 results but search can accumulate up to 1,000 validated entries across the enabled engines. The host search is bounded by 40 polls / ~50 seconds. A partial indicator remains truthful if engines are still running when the limit is reached.
- A result can add a torrent only through the existing explicit magnet selection and approved destination picker; neither sorting nor searching automatically adds downloads.

## Host: update required for streaming

**The client .deb alone does not upgrade the reference host's restricted search service.** The matching host modules are `server/download_search.py`, `server/owner_games_request.py` and `server/owner_games_ssh.py`. These must be installed together after checking exact existing files and taking a reversible backup. Do not change Docker, Gluetun, qBittorrent, Wolf, Jellyfin, Tailscale or existing media paths. Other native Transfers functions require the previously identified matching backend modules.

**Reference-host critical search engines:** Torrents-CSV (`torrentscsv.py`) and LimeTorrents (`limetorrents.py`), previously observed under qBittorrent's Nova engines directory. They must be preserved; do not silently replace these existing Python plugins or fetch unreviewed scripts.

## Test status and rollback

Source build, GTK Search controls/column order, owner-side request validation, search transport, progressive offset paging and package smoke tests are checked in CI. **This exact new client and host streaming protocol has not yet been physically exercised on the owner's machines.** Do not confuse a successfully published .deb with Private Alpha 1 end-to-end acceptance.

If the new client misbehaves, reinstall the immutable v1.21.2 or v1.21.1 package from older GitHub Releases. Restore all modified host modules from their corresponding backups. Keep owner SSH keys, Steam, Jellyfin, torrents and VPN configuration untouched.
