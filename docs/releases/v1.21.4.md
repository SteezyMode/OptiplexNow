# NOW v1.21.4 — Current Alpha

**The official Linux amd64 client installer, built from the October 29 main branch.** This is an installable owner-operated alpha, not Private Alpha 1 end-to-end acceptance.

## Videos
- The Videos main tab is now a native landing screen with **Watch in NOW** and **Open in Browser**.
- Optional WebKitGTK embedded Jellyfin playback reuses the host-bound owner-authorized discovery; the external browser remains available as fallback. Leaving Videos stops embedded playback instead of continuing invisible audio.
- Video Settings offers a private per-device tray shortcut preference: browser (default) or in-app.

## Downloads
- Progressive qBittorrent Search displays results as they arrive without a More Results button, and can accumulate up to 1,000 bounded search results. Name, Size, Seeders, Leechers and Published are clickable sortable columns.
- The client can consume up to 40 validated search updates, including final state. No downloads are added until the owner explicitly selects a magnet and approved destination.
- The previous native Transfers and owner-controlled torrent actions remain in the package.

## Host compatibility and safety
- **Installing this .deb upgrades the NOW desktop application only.** The separately adopted host-side restricted backend must be version-matched for the newest Search, Transfers and management actions. Installing the client .deb on a host does not update or reinstall those host broker modules.
- Preserve the existing Torrents-CSV (`torrentscsv.py`) and LimeTorrents (`limetorrents.py`) qBittorrent plugins; do not reinstall or alter their containers or VPN to update the desktop client.
- Existing Steam, Wolf, Jellyfin, Gluetun, torrents, media, Tailscale and owner keys must remain untouched.

## Validation and rollback
- Source/main validation on commit `24f2aa3174d43294643106032e6d51442661ea45` passed build/install, native sanitizer and regression checks. This tagged source is rebuilt and checked again by the publishing workflow.
- Native embedded video/audio/fullscreen/codec/controller playback and the latest host/backend combination **have not yet been physically accepted**. Clean-host provisioning, tunnel-failure and fresh-client gates remain open.
- To roll back the desktop client, use a prior immutable release .deb (v1.21.3). The release assets include SHA256SUMS.
