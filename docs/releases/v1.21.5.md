# OptiPlex NOW v1.21.5 — Current Alpha

**One package for the desktop and its approved owner host code.** This is the official Linux amd64 installer for owner-operated alpha devices, replacing v1.21.4.

## Unified package update
- The same .deb now contains the restricted Games, Videos/Jellyfin discovery, Search, Transfers, protected download destination and management broker modules, including their dependency graph. These files live in a root-owned package directory. There is no separate host-source download for later code updates.
- A manually adopted, previously configured owner-only Linux host has a **one-time** Host Setup action: **OWNER HOST | USE PACKAGED UPDATES**. It switches previously approved SSH forced-command entries from the legacy home-directory module to the package-owned module after explicit owner confirmation. It preserves other keys, saves a private backup, verifies the result, and refuses ambiguous or unsafe configurations.
- After that one-time adoption, installing the next NOW .deb on the host updates its restricted backend and the desktop together. No compile, Git checkout, Python source copying, or VPN/container reinstall.
- On a client without an already-approved host, .deb installation only installs code. It never silently edits SSH credentials or grants privileged host access. This fix does not claim turnkey Wolf/Jellyfin/qBittorrent clean-host setup.

## Existing desktop functionality
- Native Videos landing, owner-verified in-app Jellyfin option and browser fallback with private tray preference (introduced in v1.21.4).
- Progressive sortable qBittorrent search and native Transfers/owner controls. Source behavior from the October 29 validated main branch remains unchanged.

## Boundaries, evidence and rollback
- Packaging and installed-package import tests, isolated forced-command migration and refusal/rollback tests, GTK/native regressions and sanitizer checks must pass in CI before publication.
- This .deb does NOT change Wolf, Steam state, Jellyfin, qBittorrent, Gluetun, VPN configuration or torrent search plugins. It never auto-approves a device or exposes unrestricted SSH.
- **Real OptiPlex migration and fresh-client Games, embedded playback, VPN kill-switch, clean disposable-host setup are NOT yet physically accepted.** Full Private Alpha 1 remains open.
- The one-time SSH authorized_keys migration creates a private backup with the exact previous bytes. If rollback is needed, restore that backup only after deliberate owner review; an older .deb alone does not undo this host binding. v1.21.4 remains available for client-code rollback.
