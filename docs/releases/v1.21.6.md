# OptiPlex NOW v1.21.6 — Current Alpha

**Visual consistency update on top of v1.21.5.** The same official Linux amd64 .deb still includes the package-owned owner-only host Games, Videos and Downloads backend.

## Native Videos and Downloads styling
- Videos WATCH IN NOW / OPEN IN BROWSER buttons now use the existing NOW charcoal/dark text system instead of bright GTK defaults; the primary action uses the app's coral accent.
- Downloads Refresh, Advanced VueTorrent, Back, native Search submission, sortable result headers, Previous/Next pagination, Transfers torrent operations and folder destination buttons use consistent dark themed controls with light labels, modest borders and visible hover/focus/disabled states.
- No change to search, torrent management, VPN, Jellyfin, Steam or game streaming behavior. Downloads Search was physically reported working on v1.21.5 after package-owned host migration, so this is intentionally UI-only.

## Install/upgrade
- The same Debian installer installs on Mint/Pop!_OS/Ubuntu owner-operated clients and on the approved host. For a previously migrated owner host, the restricted broker already loads from the package-owned folder and updates with the desktop package.
- Upgrades do not change authorized_keys, owner permissions, Steam, Wolf, Jellyfin, qBittorrent, critical search plugins, containers or Gluetun.

## Evidence and acceptance
- GitHub CI includes native sanitizer, package install, GTK smoke, button-theme regression and existing host security tests. Real physical GTK visual review on MacBook/Mac mini remains appropriate.
- This is not a claim that fresh host provisioning or all Private Alpha 1 acceptance gates have passed. v1.21.5 remains an immutable rollback release.
