# OptiPlex NOW v1.21.7 — Current Alpha

**Continuous scrolling in native Downloads Search.** This official Linux amd64 .deb replaces v1.21.6 and includes the same package-owned approved host backend and consistent dark button styling.

## Downloads Search
- Results from the already-working streaming qBittorrent plugin search are all visible in **one scrollable results table**. Previous/Next pagination and the 20-visible-row limit are removed.
- New results arrive in the same sortable list as the Search continues. Scrolling down can reach newly loaded results; new APPEND frames do not intentionally jump the user back to the top.
- Existing sort controls still apply to the entire accumulated list. Clicking a header explicitly re-sorts and returns to the top.
- The existing 1,000-result cap, read-only search and explicit magnet/destination selection rules remain unchanged.

## Host, Videos and safety
- **This release changes only the desktop Search presentation.** No host broker, SSH, qBittorrent plugins, VPN, Wolf, Jellyfin, Steam, torrent files or protected actions changed.
- The previously confirmed Search function from v1.21.5 and v1.21.6 remains the exact same host protocol. No one-time host migration needs repeating.
- In-app Videos playback was reported failing by the owner. It is **not** claimed fixed by this release; the existing browser fallback remains available.

## Testing
- Source and installed-package regressions, including Xvfb GTK tests of 100 visible result rows, scrolling through later rows, 25 live APPEND rows and stream completion, must pass before publication.
- Actual on-device scroll use and embedded playback remain physical acceptance checks. Full Private Alpha 1 remains open.
- The immutable v1.21.6 release remains a rollback for the desktop.
