# OptiPlex NOW v1.21.8 — Current Alpha

**One Linux amd64 .deb for clients and approved host code.** This polish release follows v1.21.7 and preserves its fully scrolling progressive Downloads Search and package-managed restricted host.

## Browser-first Videos
- A consistent dark VIDEOS landing screen provides one **OPEN VIDEO LIBRARY ↗** action, a compact VIDEO SETTINGS expander and server settings.
- The action uses existing authorized, host-bound Jellyfin discovery and the default browser; Jellyfin retains its own account and library permissions.
- The unreliable embedded-WebKit **Watch in NOW** action and player stack have been removed from the active UI. Videos tray always opens the authorized browser path. Existing private tray preference files are preserved, but the deprecated in-app choice is ignored.

## One dark GTK theme
- Shared package-owned GTK3 palette covers buttons, input fields, dropdowns, scrollbars, popovers, dialogs, selection/focus/disabled states, and fallback controls otherwise displayed white.
- Applied to the main NOW window, Host Setup and owner approval/enrollment, Jellyfin host setup and owner host-upgrade dialogs. Explicit coral primary, danger and navigation styling takes precedence.

## Dashboard Download VPN status
- Compact DOWNLOAD VPN badge appears beside the Server Online/Offline indicator, using host diagnostics; Downloads retains detailed Gluetun status.
- Healthy denotes only container health; this is **not** verified VPN egress or kill-switch fail-closed behavior. When host health can't be checked, the badge is UNKNOWN rather than green.
- No change to Wolf, Steam, qBittorrent, VPN, Jellyfin, Tailscale, owner SSH keys, existing downloaded media or approved search plugins.

## Validation and remaining alpha work
- Source/regression tests, package installation and GTK startup/sanitizer checks must pass at the tagged release head. Visual review on Mint, Pop!_OS and Ubuntu is still required.
- Private Alpha 1 needs fresh-client setup, real gameplay, real Jellyfin browser playback, managed download paths and independent VPN tunnel-outage tests plus a clean disposable-host install before release acceptance.
- Natsuyo's Ubuntu laptop can be a supervised trial for installer/discovery/video; do not give a guest independent owner-only Downloads credentials.
- Previous v1.21.7 remains an immutable rollback.
