# OptiPlex NOW v1.21.9 — Current Alpha

**Search progression and Dashboard VPN label correction.** The same official amd64 .deb updates approved clients and the already-migrated host broker. Nothing needs compiling on an owner's laptop.

## Downloads Search
- The earlier scrolling release removed the old 20-row pager, but owner testing on v1.21.8 still encountered an initial batch of about 25 results with no visible later batches.
- qBittorrent's search protocol provides a live total and offset-based incremental results. The approved, same-job Search collection window is expanded from 40 polls / 50 seconds to **120 polls / 150 seconds**, retaining its 1,000-result cap and transient search job cleanup. The client accepts the corresponding bounded number of streamed frames.
- The native GTK list keeps every validated row while newer results arrive; the results line displays the host-reported total when it exceeds received rows.
- When this bounded search window ends while an upstream plugin still reports Running, the UI **stops saying "searching..." indefinitely** and explains that some plugins did not finish. This is not a promise that every plugin will return more than 25 results; a live qBittorrent check is still needed.
- No fallback to untrusted torrent websites, no new download endpoints, no plugin replacement, no automatic torrent adding, and no Gluetun changes.

## Dashboard
- Match the already-established Downloads wording: **VPN: HEALTHY**, **VPN: UNVERIFIED** and **VPN: UNKNOWN**. The detailed VPN information remains in Downloads.
- VPN health still represents observed Gluetun/container status, not a tested tunnel-kill-switch. No egress safety is claimed without separate verification.

## Verification and acceptance
- Regression tests simulate a plugin returning its first 25 hits, then 45 more after 70 polls; check the initial and append frames, single qBittorrent job, cleanup, 120-poll bounded no-progress search and client capacity for 121 frames.
- Tagged package tests, native GTK smoke and sanitizers must pass before publishing. Physical Mint client tests must confirm that actual plugins continue returning results beyond 25 before Search can be considered fixed in the real environment.
- All independent Private Alpha 1 gates (fresh client, independent game, real video, protected file paths, VPN outage and disposable fresh host) remain open.
- Immutable v1.21.8 remains available for rollback.
