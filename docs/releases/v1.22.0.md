# Bruiser / OptiPlex NOW v1.22.0 — Private Alpha milestone

**Release date:** November 4, 2026  
**Stage:** Owner-operated Private Alpha 1. Not a public/general-availability release.

This release marks the first integrated private-alpha build of Bruiser's daily-use Linux desktop client, spanning Games, Video, VPN-isolated Downloads/Files, and Music. The underlying package/repository are still named **OptiPlex NOW** during the Bruiser branding transition.

## Music: Discover is the front door

- Music now **opens directly to Discover**, the populated recommendation and discovery experience verified by the reference owner.
- The empty **Home** button and blank "Music Home" startup state are removed. The internal Home transport is retained for a possible later personalized dashboard, but is not shown to users.
- Discover is selected in the sidebar on entry; the search bar still searches the music catalog. **Your Library** still provides songs, albums, artists, playlists, likes, recently played albums, and new additions.
- Discover titles remain clear: no misleading "Discover · N items" counter or invented entries.

## Included integrated capabilities

- Locally played and navigable music library with search, favorites, playlists, albums, tracks, shuffle, volume, seek, and compact playback controls.
- Discover recommendations and catalog search remain suggestion-only. **Liking and browsing never automatically download or request music.** A user explicitly chooses Add to Library or Add Song.
- Artist discography and single-song catalog requests are included from v1.21.19.
- Discover retains real last-good recommendations across temporary server-refresh gaps; bounded retry/authorized cache refresh remain in place.
- Artwork improvements and the separate, rollback-protected host-side v3 resolver remain part of the source distribution. This desktop .deb does not change host Docker services.
- Games, Video, GPU control and Downloads/Files integrations carry forward without intentional changes in this Music navigation release.

## Installation

- The primary amd64 Linux installer is **OptiPlex-Now_1.22.0_amd64.deb**, with **OptiPlex-Now_amd64.deb** as the current-release convenience filename and **SHA256SUMS** alongside.
- Install the published package on approved clients. It replaces an earlier OptiPlex NOW package in place and preserves existing user configuration.
- The reference host requires no new DroppedNeedle image deployment for this Discover-first UI change. Previously installed artwork v3 stays intact.

## Validation and acceptance boundaries

The release workflow rebuilds the immutable versioned .deb and runs compilation, unit/contract tests, GTK smoke tests, installed-package smoke tests, and native sanitizer checks before publication.

The owner has verified the preceding v1.21.19 host/client Music integration, including populated Discover and restored album artwork, on the reference setup. The new Discover-first navigation must still be checked after installing v1.22.0.

**Private Alpha 1 is owner-operated**, not a certification for arbitrary fresh-host installs or independent testers. Clean-host provisioning, third-party enrollment, revocation/security and broader hardware acceptance remain tracked separately in [the Private Alpha release contract](../PRIVATE-ALPHA.md). They are not silently marked complete by this milestone.
