# Bruiser / OptiPlex NOW v1.22.2 — Downloads usability

This focused release updates the Linux client without changing the owner host, Jellyfin, VPN, media directories, downloaded torrent data, or existing qBittorrent jobs.

## Downloads: destination picker works without SFTP URI matching

- Selecting a torrent search result now opens the existing **in-app approved-drive/folder browser** instead of the OS SFTP chooser, whose exact hostname/user/URI check rejected otherwise valid remote folders.
- Choose one of the writable OptiPlex storage roots already approved by the qBittorrent owner broker, navigate to an existing directory, then click **Add Torrent**. No arbitrary client-local paths are accepted. The restricted broker still validates every destination.
- Existing Favorites, Recents, folder filtering, in-app navigation and create-folder controls remain available. Downloads are never automatically submitted merely by selecting a folder.

## Downloads: transfers are easy to locate

- **Active, Stalled, Completed, All** category tabs with item counts.
- **Active** is the initial view and shows unfinished torrents instead of burying a current film download beneath completed TV-season torrents.
- **Stalled** includes stalled download/seeding states. **Completed** includes all torrents with 100% reported progress; **All** shows everything. Filters persist across background queue refreshes.
- Existing right-click controls to pause, resume, recheck, inspect files, remove, or delete are unchanged.

## Verification and scope

The v1.22.2 source passed the GitHub main-branch full build-and-test suite and native sanitizer suite before release preparation. The guarded release workflow must independently rebuild and rerun its checks before publishing a versioned installer and the rolling main installer.

No separate host deployment is required. Installing this .deb does not touch any running torrent, VPN gateway or media file. Verify on the owner's actual Mac mini that picking a writable folder and adding a download succeeds, and that transfer filters show the expected qBittorrent queue.

This remains an owner-operated **Private Alpha** maintenance release.
