# Bruiser / OptiPlex NOW v1.22.3 — Downloads after restart, including on the owner host

This narrow private-alpha release incorporates two owner-observed fixes into the **same** Linux installer. It builds on v1.22.2 and does not redesign Downloads.

## Native download destination picker (PR #293)

- Fixed a cold-start GTK visibility problem: after a torrent result is selected, the destination view now shows the folder pane, controls, and Add button rather than leaving the embedded view hidden.
- The owner installed and confirmed the PR #293 preview on the Pop!_OS Mac mini on November 9.
- The existing approved remote host drive list, nested folders, explicit confirmation, and restricted path checks are unchanged.

## Download management from the OptiPlex host itself (PR #291)

- Preserve the local-owner Downloads route introduced and physically tested with manually installed host files on November 7. The host no longer needs to pair to its own Wolf client for local Downloads.
- The login-owner-only path calls the existing validated Downloads operations and broker, not an additional downloader endpoint. Existing approved remote NOW devices still use the same forced-command restricted SSH path.
- The separate host-local entrypoint is included in the Debian package under the existing owner-bridge files, so a normal client upgrade does not silently overwrite the manually installed fix with the older implementation.
- No automatic host configuration, Wolf policy change, Docker daemon restart, Gluetun/VPN rewrite, qBittorrent credential change, or media move.

## Validation and upgrade safety

- GitHub source validation and native diagnostic checks are required before publication. Direct end-to-end post-upgrade testing on both host and remote Mac mini remains owner-observed acceptance, not inferred from CI.
- **On the OptiPlex, preserve any manually installed host owner-broker files/config before upgrading**; Debian packaging updates installed code but does not reconfigure the host policy.
- Install the identical v1.22.3 `.deb` on the Mac mini and OptiPlex host, then verify Search → select → folder → Add and current Transfers on both. Verify the VPN gateway separately.
- The source and installed launcher are still called OptiPlex NOW pending a compatibility-safe Bruiser rename. This is not a brand or UI modernization release.

Rollback: the previous immutable v1.22.2 package remains available, but it lacks the local owner Downloads patch; restoring that behavior on the host would also require the original reviewed manual host files.
