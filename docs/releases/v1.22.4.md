# v1.22.4 — Tailscale-first household alpha baseline

**November 9, 2026. Personal-owner Private Alpha.** This release makes the existing Linux client easier to connect and ensures that the next-stage automatic Wolf work is preserved in the official versioned codebase. It is **not** a completed fresh-device or multi-user enrollment release.

## Changes versus v1.22.3

- **Owner Downloads host fix (#296).** The native GTK Downloads page no longer rejects the logged-in OptiPlex host merely because it has no client Wolf/Games key. It delegates the authorization decision to the already installed host-local or restricted-SSH Downloads backend. No downloader, VPN, Wolf, or host policy configuration is changed.
- **Already connected Tailscale first run (#297).** A fresh client with no saved server automatically starts the existing bounded server-peer search when Tailscale is already connected. The selected server is still confirmed by the user; any peer's open GameStream port is only a discovery hint, never service authorization. The current wizard already offers supported graphical Tailscale installation and sign-in guidance. No Tailscale installation or login is forced by this update.
- **Owner-only Wolf auto-pair helper (#298).** An explicitly disabled pilot, packaged for later hardware testing, reuses Moonlight Qt's supported PIN CLI and the OptiPlex's existing source-authenticated, owner-only Tailscale Wolf broker. Existing working Moonlight pairings are never changed by the pilot. The normal Games page does not invoke it; no Wolf listener is started during installation.

## What has and has not been verified

All three source PRs individually passed full CI/sanitizers and were merged into main. Actual Mac mini / OptiPlex owner-side checks confirmed Tailscale running, Moonlight already paired, SFTP batch access working, Jellyfin host discovery available, Wolf container running, and host-local Downloads broker installed. A temporary owner-bound Tailscale Wolf broker **successfully accepted a fresh pairing preparation request**, but **no new Moonlight pairing or first-time NOW service grant has been physically tested** because all household computers are already paired.
