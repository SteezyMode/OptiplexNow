# v1.22.5 — Three-button server power dashboard

**November 13, 2026. Owner-operated Private Alpha.** A small, CI-tested client UI update over v1.22.4.

## Changes versus v1.22.4
- Dashboard SERVER POWER row now shows only **ON / RESTART / OFF**. The existing WAKE action is relabeled ON; Sleep is removed; Restart and shutdown retain their original code paths, confirmation dialog and credentials. The live ONLINE/OFFLINE indicator is unchanged and not clickable.
- Compact layouts reflow the three buttons without adding another control, listener, state display or service.
- Prior v1.22.4 Tailscale-first client onboarding, Games/Wolf, browser-based Jellyfin, Downloads, Music and file access remain unchanged.

## Validation scope and remaining physical checks
- Code and regression tests must pass package/installed smoke tests, native diagnostics and GitHub release CI. This is a packaging / UI update, **not** proof that host power commands work on the actual home hardware.
- ON requires a previously configured, trusted LAN-side wake relay reachable from the client over Tailscale. Powering on from complete shutdown (rather than waking from sleep) remains to be tested on the reference OptiPlex.
- OFF / RESTART require the existing owner-approved SSH and host sudo permissions. No live host power state is changed by publishing or package installation.
- Before traveling, on the MacBook check Tailscale connectivity, Jellyfin opening in its browser and a real video playback over a separate network (phone hotspot). Leave the OptiPlex powered on and Tailscale connected. No public Jellyfin exposure or port forwarding is required.

**Rollback:** [v1.22.4](https://github.com/SteezyMode/OptiplexNow/releases/tag/v1.22.4) is immutable. Install its versioned Debian package if the newer client UI has a regression; existing settings and Moonlight keys stay in the user's home directory.
